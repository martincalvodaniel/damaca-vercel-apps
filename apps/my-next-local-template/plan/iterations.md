# Iteraciones

El contrato común de planificación para esta app se estableció en la entrega transversal [AGW-01](../../../plan/iteration-log.md#agw-01-centralizar-el-flujo-y-el-contrato-documental). El [workflow raíz](../../../plan/workflow.md) es el único protocolo.

## 01 — Definir producto de destino

- Estado: `pending`; requiere requisitos humanos.
- Objetivo: definir usuarios, problema, MVP, idioma, acceso, datos, exclusiones y éxito.
- Rutas: `plan/master.md`, `plan/iterations.md`, `plan/iteration-log.md`; ampliar solo según la petición recibida.
- Dependencias: petición humana de producto.
- Aceptación: decisiones y dudas explícitas; alcance/exclusiones acordados; primeras entregas ordenadas con aceptación verificable.
- Validación: coherencia, enlaces locales y `git diff --check`; validar código si el alcance lo requiere.

No hay otras funcionalidades futuras implícitas. Las entregas anteriores están en [archivo histórico](archive/2026-10-24/README.md); las diez evidencias recientes permanecen en el [registro](iteration-log.md).
